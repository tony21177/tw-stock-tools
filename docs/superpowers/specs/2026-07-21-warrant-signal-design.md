# 權證量能訊號策略 — 設計文件

**日期**：2026-07-21
**狀態**：設計已核准，待寫實作計畫

## 一句話

偵測全市場「權證爆量」的現股，用認購/認售量能失衡判斷方向，預測現股短期可能大漲或大跌。**先回測驗證有無 edge，有效才上線。**

## 核心假設與已知陷阱

**假設**：當有人預期某現股即將大幅波動，會用權證（槓桿）布局，使該現股的權證量能異常放大，且認購/認售的失衡透露方向。

**⚠️ 造市陷阱（本策略最大風險）**：權證成交量**主要由發行券商造市/避險（delta hedge）驅動**，不全是方向性下注。單看絕對量沒有意義。萃取訊號的方法：
1. 用「爆量 vs 自身基準」過濾造市日常噪音；
2. 用「認購/認售失衡 vs 自身基準」定方向（純避險的買賣較平衡；結構性偏差用相對基準校正）；
3. 牛證/熊證方向意圖最明確（時間價值衰減少、近線性），加權納入。

以上全是**先驗假設，正是回測要驗證的**。

## 元件與資料流

### 1. 資料層 `warrant_flow.py`（新模組）

- `fetch_warrant_day(date)`：抓當日全 type 權證 → 每筆 dict（代號、標的代號、購/售、成交金額、股數…）。帶 retry + delay（避 TWSE 限流）。
- **權證條款 cache** `cache/warrant_terms/{code}.json`（或單一彙總檔）：代號 → 發行券商、履約價、到期日、行使比例。`ensure_terms(codes)` 增量填充，只抓沒看過的代號。
- `aggregate_by_underlying(rows, terms, stock_close)`：按標的代號彙總 →
  - `call_turnover` = Σ 認購成交金額（+ 牛證）
  - `put_turnover` = Σ 認售成交金額（+ 熊證）
  - `call_vol` / `put_vol`、權證檔數、發行券商分布
  - 每檔標的的「主要貢獻權證」（成交金額最大的前幾檔，含券商/履約價/距到期天數/價內外）
- 日檔 `cache/warrant_flow/{date}.json`（逐日累積）。
- **近到期過濾**：距到期天數 < N（如 5-10）且深度價外的權證，其爆量多為出清而非訊號 → 彙總時可選擇性排除或降權（回測決定）。

### 2. 訊號 `warrant_signal.py`

`build_signal_rows(day_files)` → 每檔標的：
- **爆量倍數** = 今日權證總成交金額 ÷ 近 20 日均；≥ 門檻（回測定，如 2-3x）才入選
- **權證/現股量占比** = 權證總成交金額 ÷ 現股成交金額（相對活躍度）
- **認購佔比** = call_turnover / (call+put)；**Δ = 今日佔比 − 20 日均佔比**（相對自身，非絕對 0.5）
- **方向標記**：
  - 🔥 偏多（爆量 + 認購佔比升）→ 可能大漲
  - ❄ 偏空（爆量 + 認售/熊證放量、認購佔比降）→ 可能大跌
  - ⚡ 中性（爆量但失衡不明顯）
- 附：發行券商分布、主要權證明細（履約價/距到期/價內外）

### 3. 回測 `warrant_signal_backtest.py`（**第一個交付，決定要不要上線**）

事件研究（比照 `tw_turnaround_backtest.py`）：
1. 逐日抓過去 3-6 個月權證資料 → cache（一次性、之後讀 cache）
2. 每日每檔算爆量×失衡 → 標記 🔥偏多 / ❄偏空
3. 訊號日後 **1/3/5/10 交易日**現股報酬（FinMind 收盤）
4. 對照全市場基準；**分方向驗證**：🔥 是否偏漲、❄ 是否偏跌（勝率、中位數、平均超額、t 統計量、CI）
5. 參數掃描：爆量門檻、失衡 Δ 門檻、持有天數、近到期過濾開關
6. 輸出回測報告頁（比照現有 6 個回測頁），**誠實呈現有無 edge**
7. **若某方向無 edge**（如偏空因認售稀薄失效）→ 只留有效方向、或標明不可用；若全無 edge → 停在此步、記錄結論、不硬上線

### 4~6. 上線層（**回測有 edge 才做**）

- **每日盤後掃描 cron**（收盤權證資料出來後，約 18:00-20:00，is_trading_day 守門）→ 只留通過回測的方向/門檻 → 存 `cache/warrant_signal_history/{date}.json`
- **網頁分頁 `/warrant-signal`**：當日訊號現股表（代號/名稱、權證總量、爆量倍數、認購佔比及 Δ、方向標記、券商分布、權證檔數、量占比）；每檔可展開看主要貢獻權證（券商/履約價/距到期/價內外）；術語白話 + 造市陷阱 + 先驗未回測 caveat 盒（比照族群資金流）
- **LINE/TG 推播**：每日 🔥偏多 Top N / ❄偏空 Top N，各附爆量倍數 + 認購佔比；併入 `line_push.py` 共用模組，收件群組另定

## 開發順序（嚴格）

1. 資料層（抓取 + 條款 cache + 彙總 + 日檔）
2. **回測**（驗證 edge，出報告頁）→ **驗證通過才繼續**
3. 每日掃描 + JSON 歷史
4. 網頁分頁
5. LINE/TG 推播

## 風險與 caveat

- **造市陷阱**（見上）— 核心風險，靠失衡法 + 相對基準 + 牛熊證加權 + 回測驗證處理
- **認售權證量體小** → 偏空（大跌）訊號樣本可能不足；回測會判定偏空半邊能不能用
- **近到期價外權證出清** 造成假爆量 → 用距到期天數過濾（回測決定門檻）
- **歷史抓取成本**：~27k 筆/日 × ~120 日；逐日 cache、加 delay 避限流
- **條款來源未定**：履約價/到期日的機器可讀來源實作階段釘死；退路是 best-effort（發行券商靠名稱仍可上）
- **權證 ≠ 因果**：券商避險會反身影響現股（reflexivity），訊號是相關非因果，僅輔助判讀
