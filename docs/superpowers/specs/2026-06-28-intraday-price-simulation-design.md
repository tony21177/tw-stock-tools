# 股價盤中走勢模擬系統 — 設計 (spec)

日期：2026-06-28
狀態：設計已與使用者確認，待寫實作計畫

## 目標 (Goal)

給一檔股票，根據它的籌碼 / 型態 / 量價狀態，模擬「明天」開盤到收盤
(09:00–13:30) 的盤中走勢，並在網頁上**並列三種**呈現：

- **A 情境劇本**（機率加權，相似日分群）
- **B 最可能路徑 + 信心帶**（相似日逐分鐘分布）
- **C 純蒙地卡羅**（不看籌碼的統計對照基準）

像台股 App 的「分時走勢圖」。

### 核心誠實原則

盤中精確路徑本質不可預測。本系統**不宣稱預測那條曲線**，而是：
用「過去籌碼/型態最像今天的日子，它們隔天實際怎麼走」說話 (A2 相似日法，
資料驅動、可回測命中率)。三張圖各自標註用什麼方法、樣本數、相似度，
並標明 caveat。C 蒙地卡羅當「沒有任何資訊優勢」的對照基準。

## 何時跑 / 已知什麼

- 使用情境：收盤後(或盤前)輸入股號，預測**下一個交易日**。
- 已知：今天收盤價 + 今天/歷史的籌碼、型態、量價。
- 未知：明天開盤跳空 → 由相似日的「隔天開盤跳空分布」一併預測。
- 所有路徑 **rebase 成「距前一日收盤 %」**，使不同股、不同日可比較；
  開盤跳空是被預測的一部分。

## 架構與位置

- 新工具 `tw_intraday_sim.py`（核心引擎，可 CLI 跑、輸出 JSON）。
- Flask 路由 `/intraday-sim`（輸入股號，`concept_momentum/app.py`）。
- dashboard 加分頁入口（族群動能那排或單檔查詢排，屬單檔查詢工具 → 放單檔查詢組）。
- 資料源：
  - FinMind 日線（特徵向量、相似度比對）— 已有快取機制。
  - FinMind `TaiwanStockKBar`（分鐘 K，09:00–13:30 約 265 根 OHLCV）—
    **一次抓一天**，相似日的隔天分鐘路徑用它，**快取**到 `cache/kbar/<code>_<date>.json`。
  - FinMind 借券(`TaiwanDailyShortSaleBalances`)、融資
    (`TaiwanStockMarginPurchaseShortSale`)、法人
    (`TaiwanStockInstitutionalInvestorsBuySell`) — 歷史籌碼特徵。

### 資料可行性結論（已驗證）

- ✅ `TaiwanStockKBar` 單日可取（測 6451 得 265 根 1 分 K）。
- ✅ 借券/融資/法人 FinMind 有完整歷史。
- ❌ **分點主力 BSR 無歷史 API**（TWSE 只有當日）→ **不進相似度比對**，
  僅用於「今天這檔」的 A3 白話解讀。

## 特徵向量（描述「今天狀態」）

標準化(z-score)後算歐式距離。**v1 不加權**。

**籌碼面**
- 借券賣出餘額 5 日變化 %
- 融資餘額 5 日變化 %
- 融資維持率位階（估算，距追繳的緩衝）
- 三大法人合計淨買超 / 當日成交量

**型態面**
- 距 5 / 20 / 60 日均線 %
- 近 5 日、近 20 日報酬 %
- 距近 20 日高/低點位置（0~100%）
- 今日 K 棒：收紅/黑、上下影線比例、是否跳空

**量價面**
- 量比（今日量 / 20 日均量）
- 量價背離旗標（漲但量縮 / 跌但量增 等）

（BSR 不在內。某日核心型態/量價特徵缺值 → 該日不納入比對池；
籌碼特徵單項缺值 → 該項以池內中位數補，其餘照算。）

## A2 相似日引擎（核心）

1. 算「今天」特徵向量。
2. 在兩個搜尋池各找最像的 K≈40 天（標準化歐式距離，由近到遠）：
   - **池①「這檔自己」歷史**（個股慣性，樣本少）
   - **池②「全市場所有股票日」**（樣本多、通用型態）
3. 取這些相似日的**隔天**分鐘 K → rebase 成「距前收 %」的逐分鐘路徑
   （對齊到 09:00–13:30 的 ~265 個時間格）。
4. 兩池各自產出 A/B/C，網頁分池顯示（或標明來源）。

## A / B / C 三種呈現（網頁並列三張，各帶方法註解）

- **A 情境劇本**：把相似日隔天路徑**用透明規則分群**（不用 k-means，
  以可命名為原則）：依 (開盤跳空: 高/平/低) × (收盤 vs 開盤: 走高/平/走低)
  切成具名劇本（開高走低、開低走高、開平走高、高檔盤整、開低走低…），
  小桶(佔比 < 8%)併入鄰近桶。每群：機率 = 該群佔比、代表路徑 =
  群內逐分鐘中位數、+ A1 規則微調、+ A3 白話理由。
  **註解**：「用過去 N 天籌碼/型態最像今天的日子，它們隔天走勢分成這幾群。」
- **B 最可能路徑 + 信心帶**：所有相似日路徑的**逐分鐘中位數**為主線
  + 25/75（並可選 10/90）百分位扇形帶。
  **註解**：「N 個相似日隔天走勢的逐分鐘中位數與分布。」
- **C 純蒙地卡羅**：不看籌碼，用該股的「開盤跳空分布 + 盤中波動度」
  隨機模擬 N≈500 條路徑 → 畫機率雲 / 百分位帶。
  **註解**：「純統計：只用該股波動度隨機模擬，當沒有資訊優勢的對照基準。」

### A1 規則微調（輔助、輕量）

少量透明規則對 A 的劇本機率做小幅 tilt + 產生解釋字串，例如
「借券賣出餘額連增 + 跌破 5 日線 → 開低走低機率 +、列為理由」。
v1 只做輕量幾條，可調，不主導機率。

### A3 白話解讀（LLM，不決定機率）

頁面附一段白話：今天籌碼(含 BSR)/型態重點 + 三種模擬的綜合提醒。
v1 可由產生頁面時帶入文字模板 + 關鍵數據；不讓它決定機率。

## 圖表規格

- x 軸：09:00–13:30（~265 分鐘格）。
- y 軸：**雙軸** — 左「距前收 %」、右「換算預估股價」
  (price = 前收 × (1 + %))。兩者都顯示。
- 三張圖並列（A / B / C），每張上方一行方法註解 + 樣本數/相似度。
- 成交量子圖 **v1 不做**（YAGNI）；之後可加「預期量能曲線」。

## 誠實 / 校準

- v1：頁面標 caveat（不可預測、僅情境參考）+ 顯示樣本數、相似度、
  資料區間、universe。
- v2（之後）：**校準回測** — 「相似日法的劇本隔天實際命中率」。
  跟我們既有回測同精神，天生可驗證。

## 分期 (scope)

- **v1**：A2 雙池 + A/B/C 並列圖（雙 y 軸）+ A1 輕量規則 + A3 白話 +
  caveat/樣本資訊。
- **v2**：校準回測（命中率）、成交量模擬、特徵加權、相似度法精修。

## 檔案結構

- `tw_intraday_sim.py` — 引擎：特徵抽取、相似日搜尋、KBar 取得/快取、
  A/B/C 計算、輸出 JSON（CLI 可跑 + 給網頁呼叫）。
- `concept_momentum/app.py` — `/intraday-sim` 路由 + 渲染函式
  （沿用既有頁面 css/nav 樣式）。
- `concept_momentum/concept_charts.py` — dashboard 加入口分頁。
- 快取：`concept_momentum/cache/kbar/<code>_<date>.json`（分鐘 K）、
  相似日特徵快取（避免每次重算全市場）。

## 錯誤處理

- KBar 某日抓不到 → 跳過該相似日，樣本數據實顯示。
- 相似日不足（如新股、樣本 < 門檻）→ 頁面提示樣本不足、只顯示 C
  或降級。
- FinMind 逾時 → 重試 + 友善錯誤頁（沿用既有 pattern）。

## 測試

- 引擎單元測：特徵抽取對已知日數值、rebase 對齊、相似度排序、
  分群佔比加總=1、百分位帶單調。
- 端對端：對 1-2 檔（如 6451、2330）跑出 JSON + 頁面 HTTP 200 +
  三張圖資料齊全。
