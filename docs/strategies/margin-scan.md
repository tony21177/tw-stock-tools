## 概念

找「**斷頭賣壓正在宣洩**」的股票反市場低接:核心指標是**融資餘額急減**
(斷頭/認賠強制賣出湧出),不是維持率水位。

## 篩選

近 5 日融資減 ≥8% 且股價下跌(排除獲利了結)且 5 日前餘額 ≥300 張。

## 欄位重點

| 欄 | 意義 |
|---|---|
| 5日/1日融資減% | 核心指標;1日欄抓「今天正在斷」 |
| **融資賣壓/量%** | 近5日融資「賣出」總張÷5÷近5日均量。**用 gross 賣出非淨變動**(淨值被買進沖抵會低估,如環球晶案例 7.7% vs 真實 14.9%)。>15% 紅=系統性斷頭鐵證 |
| 借券增減 | SBL 空方;綠=回補(融資斷頭+借券回補=多空雙殺,更像底) |
| 維持率 | 現價÷(遞迴成本線×成數);<130%=真斷頭非獲利了結 |
| 清洗強度 | 融資減幅−股價跌幅;🧹>0=浮額洗掉 |

遞迴成本線 = XQ/三竹口徑「今日成本=(昨成本×(餘額−買進)+收盤×買進)÷餘額」,
重用 `tw_margin_monitor.compute_recursive_cost`;已對單檔工具驗證一致。

## 五種用法(頁面「怎麼用」表)

①急殺搶反彈(1日減% 排序) ②深套落底(維持率<130%) ③大型股錯殺(5日減張數)
④浮額清洗(清洗強度) ⑤系統性斷頭警訊(賣壓/量% 排序,**等此比回落+跌停打開再低接**)。

## ⚠ 注意

還原收盤 EOD 估算;個股維持率≠整戶;單檔精確用 `/chip` 或 tw_margin_lookup;
斷頭≠保證反彈(基本面壞會續破底);非買賣訊號。
