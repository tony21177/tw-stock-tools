## 概念

歐尼爾/IBD 的 **Follow-Through Day**:熊市/修正結束的確認訊號。
底部第一根反彈可能只是跌深反彈;若反彈活過幾天後出現「大漲+量增」,
代表機構真金白銀回場 → 修正可能結束。CAN SLIM 的 M(市場方向)核心工具。

## 規則(狀態機)

1. **修正中**:收盤自參考高點回檔 ≥ 6%(`CORR_PCT`)
2. **嘗試反彈 Day 1**:創低後第一根收漲(防線 = 此前修正低點)
3. 盤中跌破防線 → 歸零重數
4. **FTD**:反彈第 ≥4 天、單日漲 ≥1.7%(`FTD_PCT`,IBD 現行;舊版 1.25)
   且 **量 > 前一日**(台股用成交金額、美股用成交量)

指數:加權 TAIEX(FinMind 2004 起)、S&P500 / Nasdaq(Yahoo 25y)。

## 回測(內建,全歷史狀態機)

*失敗 = 25 交易日內跌破反彈防線。失敗率正好落在文獻 25-30% = 演算法對上 IBD 口徑。

**結論**:edge 溫和;主要價值是「制度化再進場時機 + 明確停損線
(跌破防線 = FTD 失敗退出)」,不是預測。真轉強前常見 2-3 次失敗 FTD。
著名 FTD 均命中:S&P 2022-10-21 熊市底、2025-04-22 關稅崩後、台股 2026-04-08(後 60 日 +34.6%)。
