## 概念

Minervini 核心買點型態:Stage 2 上升趨勢中的基底,
**回檔一次比一次淺(18%→12%→6%)+ 量能枯竭** = 供給被吸收;
貼 pivot(基底右側高點)帶量突破 = 主升段買點。

## 偵測口徑

**前置趨勢模板**(先確保 Stage 2,與林則行箱型最大差異):

| 條件 | 門檻 |
|---|---|
| 均線結構 | 價 > MA50 > MA150 > MA200,且 MA200 走揚(>20 日前) |
| 位階 | 距一年高 <25%、距一年低 >+30% |
| 相對強度 | 年 RS ≥ 70 |

**VCP 本體**(近 130 日,zigzag 5% 抓 swing):

| 條件 | 門檻 |
|---|---|
| 收縮段數 | 2~6 段 |
| 深度遞減 | 每段 ≤ 前段 × 0.85;首段 ≤30% |
| 低點 | 逐段墊高 |
| 末段緊縮 | 近 10 日振幅 ≤8% |
| 量縮 | vol5 < vol50 × 0.65(乾涸值顯示於卡片) |

**兩個清單**:

- 🌀 **形成中** = 距 pivot ≤6% 且量乾涸(觀察名單)
- 🚀 **今日突破** = 收盤 > 昨日前 pivot 且 當日量 ≥1.5×vol50 → 盤後推播
