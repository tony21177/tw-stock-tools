# 🔥 個股期火熱排行

| | |
|---|---|
| 頁面 | `/stock-futures`(17 欄全可排序) |
| 模組 | `tw_stock_futures.py` |
| 排程 | 每交易日 15:30 推睏霸數錢(Top20+標記) |
| 上線 | 2026-07-24 |

## 內容

全市場個股期按成交量排名:收盤/漲跌幅/量/量增減/OI(拆近月/遠月)/
熱門標記(🔟漲跌幅前十、🚀量躍升、〰振幅、熱)+ 進階欄:

| 欄 | 說明 |
|---|---|
| 基差 | 近月期貨 − 現貨(升水+/貼水−) |
| 週轉 | 量/OI(高=當沖 churn、低=佈局) |
| 近遠價差 / 距結算 | 期限結構;近月第三個週三 |
| 法人淨 | TAIFEX 大額交易人「特定法人」淨留倉,全市場 ~262 檔 |
| 象限 | 漲跌×OI 增減 → 🟥新多/🟧空回補/🟩新空/🟦多了結 |

## 資料備註

- FinMind 全市場範圍查詢只回第一天 → 兩次單日查
- 法人淨用 TAIFEX 大額交易人表(FinMind 期貨法人只有指數期);「前十大特定法人」為 proxy
- 當日未公布(15:30 前/休市日)自動回退最近交易日並標註
- `fut_stock_set()` 供全站 ★ 標記共用
