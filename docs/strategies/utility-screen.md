## 概念

大盤修正期多數股票跟跌;**下一波領頭羊通常在修正期就異常抗跌**
(高 RS、貼高點、量縮不跌)。在市場最亂時把它們找出來放進觀察清單。

## 啟動機制(區間 RS)

- 加權距「200 日內最高收盤」**>20 個交易日** → 啟動
- 區間 RS 視窗 = **距高點天數 N**(逐日 +1)
- 大盤創高或 N>200 → 退回標準年 RS(N=250)

## RS 公式與濾網

- **區間 RS**(IBD 加權):視窗切四段,`score = 2×r₁ + r₂ + r₃ + r₄`(最近段雙倍)
  → 全市場百分位 1~99
- 濾網(文章口徑,不看一年低點):

| 條件 | 門檻 |
|---|---|
| 區間 RS | > 85 |
| 股價 | > MA200 |
| 均線 | MA50 > MA200 |
| 日均成交額 | > 1 億(近 20 日,vol×收盤估) |
| 距自身 200 日高 | < 25% |

## 呈現

統計列(符合數/距高點天數/最高 RS/平均 RS)+ **mini K 線卡片牆**
(近 120 根蠟燭 + MA20/60 + 量柱;點卡開大圖)。build 時 `_warm_kline` 預熱快取。

## 用法

觀察清單、**非進場訊號**:修正期掛名單看誰形成 VCP / 量縮不跌;
等 `/ftd` 大盤轉折,名單中最先突破買點者 = 風報比最佳。

首掃(2026-08-02,N=28、修正 −9.7%):母體 2,338 → 47 檔
(兆豐金★/華南金★/合庫金★ 貼高點、漢翔★ +25%、仁新 +71%)。
