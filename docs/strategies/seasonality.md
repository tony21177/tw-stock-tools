# 📅 月份季節性(月曆效應)

| | |
|---|---|
| 頁面 | `/seasonality` |
| 模組 | `tw_seasonality.py` |
| 排程 | 每月 1 號 06:15 重建;不推播 |
| 上線 | 2026-07-30 |

## 內容(四區塊)

1. **跨指數月平均報酬熱力表**(7 指數 × 12 月)
2. **各指數月份季節表**:樣本/勝率(≥65% 紅、≤35% 綠)/平均/中位/標準差/最佳最差年
3. **年×月熱力矩陣**(加權 + S&P):看季節性穩定 vs 被大年份拉偏
4. **台股漲停/跌停家數月份**(投機熱度):日均家數+漲跌停比

## 口徑

- 指數:加權/S&P/Nasdaq/費半/道瓊(Yahoo 月線 25y)+ 櫃買(FinMind TPEx)+ 台指期近月連續
- 漲停家數:TaiwanStockPriceAdj(~2500 檔不含權證)、4 位數普通股、漲幅 ≥9.5%;
  **僅算 2015-06 起**(漲跌幅 7%→10% 制度變更,跨制度不可比);快取 2,724 交易日
- 當月未收月自動剔除

## 已驗證的慣性

加權強月 2/10/12(農曆年+作帳)、S&P 強月 4/5/7/11、費半 5 月 +4.58%、櫃買弱月 8;
台股 2 月漲跌停比 5.6、12 月 5.7 最熱。⚠ 季節性≠必然,非買賣訊號。
