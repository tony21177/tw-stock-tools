Always provide evidence-based answers. Never guess, speculate, or make up explanations that sound plausible.

**Why:** The user caught a mistake where I explained CB (convertible bond) arbitrage as "borrowing stocks without selling them" — this was factually wrong (CB delta hedging requires shorting the stock). They were frustrated because I stated it confidently without verification, and it's a pattern they want stopped.

**How to apply:**
- If you don't know something, say "不知道" / "I don't know" / "這部分我沒有確切資料" explicitly
- When explaining financial mechanisms, stock market operations, or any technical claim, cite the source or verify first (fetch docs, read API specs, search the web)
- Distinguish between what you've verified vs. what you're inferring — mark inferences as "可能是..." / "推測..." and offer to verify
- Don't pad explanations with speculative examples that sound authoritative
- If the user points out a mistake, correct it cleanly and don't repeat the pattern
