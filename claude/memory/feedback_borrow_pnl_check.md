借券還券解讀（[[reference_chip_skill]] 紀律 1+2）的四層 caveat + 強制 chip 輸出格式。**所有跑 chip 報告解讀還券明細時都要遵守，不能再簡化。**

## 🔥 強制 chip 報告輸出格式 (2026-05-27 新加)

借券面 section **必須包含** 6 條基本數據，不能只給 borrow events 數字：

```
🔵 借券:
 1. 新借 N 張 (t13sa710 借券交易合計，利率區間)        ← 借入事件 (≠賣空)
 2. 還券 M 張 (t13sa870 借券還券明細合計)                ← 還回借券 (≠平倉)
 3. **SBL 當日真實賣空: +X 張** (SBLShortSalesShortSales)  ← ✅ 真做空增量
 4. **SBL 當日真實平倉: -Y 張** (SBLShortSalesReturns)     ← ✅ 真空頭買回
 5. SBL 期末餘額: Z 張 (CurrentDayBalance, 真實做空部位)
 6. 真實平倉 / 借券還券比例 (= Y/M × 100%) ← 打折係數，判斷還券中有多少是真平倉
```

## 🚨 必查除權息日 (2026-05-27 加，最關鍵 caveat)

跑 chip 前**強制**先查 `TaiwanStockDividend` 確認 30 天內有沒有除權息事件：

```python
finmind_client._call('TaiwanStockDividend', {
    'data_id': code, 'start_date': '近 1 年', 'end_date': '一年後', ...
})
# 看 CashExDividendTradingDate (除息交易日) / StockExDividendTradingDate (除權交易日)
```

**台股 空方部位 + 除權息規則 (TWSE)（2026-07-17 user 指正修正版）：**
- **只有「融券」(信用交易) 有強制回補** — 停止過戶日前的融券最後回補日，法規強制買回
- **「借券賣出」(SBL) 沒有強制回補**：借券人可以不還，除權息時改付「權益補償」(股利等值) 給出借人；出借人若要自己參加除權息/股東會可「提前召回」，被召回才須還
- 所以除息前 1-2 週常見的大量還券潮是「出借人召回 + 借券人自主選擇還掉避開權益補償」驅動的**常見現象**，不是全面制度強制 — 但同樣 ≠ 空方主動撤退
- 借券人常在除息後重借 (roll-over)，SBL 餘額除息後回升即為證據

**為什麼這個 caveat 最重要：**
2026-05-27 對 2313 我解讀「39K 張還券 = 軋空認賠 / 空方撤退」完全錯了。實際上：
- 2313 除息日 6/2 (現金 $2.8)，最後過戶日 5/30
- 5/26-27 還券 39K 中**只 3K 是真平倉**，36K (~93%) 是除息制度逼出來的
- 真實空方部位 (SBL 餘額) 從 19,721 → 18,084 只少 1,637 張 (-8%)
- 還的人很多在除息後會重新借券再賣空

**How to apply：**
1. chip 前必查 30 天前後的除權息事件
2. 若有除權息 → 借券還券潮要**先扣除制度性部分**
3. 真實空方意向看 SBL 餘額 (CurrentDayBalance)，不是借券還券明細
4. 除息後 1-2 週 SBL 餘額是否反彈 = 空方是否真的撤退的關鍵驗證點

**Why this format:** 2026-05-27 user explicit 指正：「這籌碼總覽 少了 當日真實的借券賣出數據」。前一版只給 borrow events (371 / 18309) 沒突出 SBL ShortSales (1,199) + Returns (1,904)，導致看不到「真實做空活動」。借券事件數字常常虛胖（因為 lending contract roll-over），SBL 系列才是真的。

**How to apply:**
- 用 `finmind_client.fetch_short_sale_balances(code, today, today, token)` 抓今日當日 row
- `SBLShortSalesShortSales` / `SBLShortSalesReturns` / `SBLShortSalesCurrentDayBalance` 三個都印出來
- 對照「新空vs近 5 日平均」判斷是否有新空進場放大訊號
- 若 SBL ShortSales 突然放大 (>5x 近期平均) → 警惕空方反撲

## ⚠ Caveat 1: 借券 ≠ 賣空（紀律 1 重申）

`TaiwanStockSecuritiesLending` (借券交易) 只是「借入」事件，借出後**未必拿去做空**。可能用於：
- 賣空（最常見，特別是高利率借入時）
- ETF 創建 / 贖回
- M&A arbitrage / 可轉債 hedge
- 集保鎖券（不賣）

**判斷暗示：**
- 借券利率 > 3% → 高機率是真實做空（賣方索高利反映需求 / 缺貨）
- 借券利率 ≈ 0.02-1% → 用途模糊，可能 hedge / 借而不賣
- 必須同時看 SBL CurrentDayBalance (真實做空部位餘額) 的變動驗證

## ⚠ Caveat 1.5: 還券 ≠ 平倉買回（2026-05-27 新發現）

借券明細的「還券」是把券還回原借出方，可能來自：
- **真正平倉買回**（先買回市場上的股票，再還給借出方）
- **契約到期 roll over**（借了沒賣或部分賣，到期換借券契約）
- **集保鎖券解除**（借了沒賣，到期還回）

**驗證方法：**
- 借券明細「合計還券」(t13sa870) — 包含上述所有情境
- `SBLShortSalesReturns` — **只算真正平倉買回**（會減少 SBL CurrentDayBalance）

**比例驗證：**
- 2026-05-27 借券還券 18,309 張 vs SBL Returns 只 1,904 張 = **10%**
- 2026-05-26 借券還券 21,099 張 vs SBL Returns 只 1,147 張 = **5%**
- → 大規模還券事件中，**真正計入空頭平倉的通常只佔 5-20%**
- → 「軋空認賠 X 億」這種結論要根據 SBL Returns / 借券還券 比例打折

**Why:** 2026-05-26 對 2313 我估算 -8.6 億「軋空認賠」上限值，但 SBL Returns 只 1,147 張，實際被計入平倉的只有 ~5% → 真實認賠規模約 4,300 萬到 5,500 萬，遠小於上限值。

## ⚠ Caveat 2: 賣空價 ≠ 借入日開盤

即便確認賣空了，賣價也分布在 OHLC 內，可能跨多天拆單。3/5 借入 8,098 張不等於 3/5 開盤 $226 全部賣出。

**驗證方法：** 對齊借入日的 `SBLShortSalesShortSales` (當日賣空量)。同日借入 ≈ 同日賣空 → 高機率同日入場；若 SBL ShortSales 隔幾天才跳升 → 賣空可能延後。

## ⚠ Caveat 3: P/L 寫區間，不寫定值

賣空價區間 (OHLC 內) → 損益是區間估算。寫法：
- ❌「3/5 lot 虧 4.7 億」(假裝定值)
- ✅「3/5 lot 浮虧區間 4.7~6.4 億（依 3/5 賣於 $226 open 或 $205 close 而定），含利息 7,500 萬」

## 必抓的關鍵 dataset

**`finmind_client.fetch_short_sale_balances(stock, start, end, token)`**
回傳每日的 `SBLShortSalesCurrentDayBalance`（真實做空部位）+ `SBLShortSalesShortSales`（當日賣空）+ `SBLShortSalesReturns`（當日還券）。

跑 chip 時必抓近 3 個月 SBL 軌跡，畫成表看：
- 高峰在哪一天 → 空方最積極建倉時點
- 從高峰到今天減倉了多少 % → 趨勢方向
- 大規模還券事件（單日 ≥ 2K 張）的日期 → 空方撤退節點

## How to apply（強制 checklist）

跑 chip 報告解讀還券明細前，**所有步驟都要做完**才能下判讀：

1. ☑ 抓 `fetch_short_sale_balances(code, '近 3 個月', today, token)` 列日線軌跡
2. ☑ 列每個還券批次：借入日 + 張數 + 利率
3. ☑ 對每批比對借入日的 SBL `ShortSales` 量，判斷「借券 = 賣空」可信度
4. ☑ 抓借入日 OHLC，計算 P/L 區間（OPEN 樂觀 / CLOSE 悲觀 / 用 OHLC 均算中性）
5. ☑ 加借券利息估算: 利率 × 借入日股價 × 持有天數/365 × 張數
6. ☑ **算 SBL Returns / 借券還券總量比例 → 抓「真正平倉」打折係數**（通常 5-20%）
7. ☑ 結論寫「P/L 區間 -X 到 -Y 億」+「真實認賠約 -A 到 -B 千萬 (僅 N% 計入 SBL 平倉)」+「**估算**」
8. ☑ 不要再用「軋空 climax」這種絕對措辭 — 改用「軋空壓力 / 空方減倉節奏」

**單位常見錯誤：**
- 1 張 = 1,000 股
- 損益 (千元) = 價差 × 張數 → 要 ÷ 10 得萬，÷ 10000 得億
- 損益 (元) = 價差 × 股數 = 價差 × (張數 × 1000) → ÷ 10000 得萬，÷ 1e8 得億
- 別把「張」當「股」算 — 容易差 1000 倍

**永遠不要：**
- 用借入日 open 算定值 P/L
- 把「老空 / 新空 / 投機客」用利率高低硬分類（次要訊號）
- 在 SBL 軌跡沒抓的情況下下結論
- 把「借券還券明細合計」當「實際平倉量」用（要去 SBL Returns 找真實平倉）
